# Dillon Grannis - Personal Tutoring Website

A clean, professional website for virtual tutoring services built with Next.js.

## Features

- **Home Page**: Comprehensive information about tutoring services, background, and testimonials
- **Contact Page**: Email contact information
- **Responsive Design**: Works on all devices (mobile, tablet, desktop)
- **Modern UI**: Clean, minimal design with dark blue and white theme

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the website.

### Build for Production

```bash
npm run build
```

This creates a static export in the `out` directory that can be deployed to any static hosting service.

## Deployment

This is a static site that can be deployed to:
- **Vercel** (recommended for Next.js): Just connect your GitHub repo
- **Netlify**: Drag and drop the `out` folder after building
- **GitHub Pages**: Upload the `out` folder contents
- Any static hosting service
